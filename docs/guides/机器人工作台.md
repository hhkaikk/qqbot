# 大肥鱼工作台

工作台展示实际机器人状态、保留的聊天、长期记忆、Token及活动；查看接口只读，不发送QQ消息、不标记已读、不唤醒模型。费用预算可在「Token用量」中明确保存，处理诊断位于「最近活动」，详见[运行保护与诊断](运行保护与诊断.md)。

本地开发时访问桥接监听端口下的 `/dashboard/`。使用 Linux 部署模板时，可以在自己的电脑运行 `ssh -N -L 13100:127.0.0.1:13100 user@your-server` 建立隧道，再访问 `http://127.0.0.1:13100/dashboard/`；请替换示例 SSH 用户与主机。个人电脑专用的启动器不随仓库提供。隧道只为网页访问，本机关闭不会停止服务器机器人。

部署公网反代后访问HTTPS的 `/qqbot/`。页面外壳和现用卡通头像公开可加载，聊天、记忆及账本均须工作台登录密码。沿用原控制台认证接口，密码保存在服务器私有配置，不写入网页或源码。支持8至128位字母、数字、下划线或短横线；更改后旧凭据立即失效。默认仅当前标签页记住访问，勾选“记住这台设备”才持久保存。点右上角锁定可清除本浏览器的访问凭据。

## 页面与数据口径

- 总览：QQ实际账号状态、DSH连接、暂停/忙闲、自动恢复、模型配置、语音开关、累计Token、费用估算和可见会话/记忆。
- 会话聊天：按会话选取桥接缓存最近100条预览，可搜索；发言者QQ与机器人头像明确区分。长消息可能截断，不是完整QQ归档。
- 长期记忆：人物印象、当前话题、待办与想法；按会话隔离，过期待办不展示。本页不改写记忆。
- Token：权威累计来自现有DSH投影与账本；24小时/7天曲线仅为已记录的逐轮窗口，未逐轮归属的旧历史不会伪分摊到今天。缓存命中也计入输入，费用按配置价目表估算，不是官方余额。
- 活动：聊天动态使用真实消息时间并显示北京时间；旧系统日志只有时分秒时保留服务端原始时钟/时区，不虚构日期。

健康状态10秒更新，Token聚合缓存30秒；页面隐藏后暂停轮询。读取失败保留最后数据并标记过期；没有数据明确显示不可用或空状态，不能用“0”冒充。工作台本身不调用模型，因此不产生DS模型Token。

按用户指定采用DeepSeek风格蓝白配色，复用当前QQ的卡通头像快照；没有生成或替换人物。头像文件 `public/dashboard-avatar.jpg` 是公开QQ头像的本地快照，之后更换QQ头像时可单独更新本文件。

## 开发验证

```sh
node --test scripts/test-dashboard.mjs scripts/test-dashboard-routes.mjs scripts/test-dashboard-client.mjs
node scripts/dashboard-fixture.mjs
```

第二条启动 `http://127.0.0.1:4187/dashboard/`，全部为明确标注的合成演示数据，不读取生产凭据或聊天。演示令牌为 `fixture-dashboard-token`，不能用于生产。

浏览器测试使用playwright-cli启动隔离浏览器，再执行 `run-code --filename=scripts/dashboard-ui-check.js`；仅允许4187本地演示。覆盖1440/768/390/320宽度的五页面、搜索/分类、XSS、用量窗口、离线/失败、隐藏暂停及零写请求，截图在 `state/dashboard-qa/`。

## 部署与撤回

后端由既有桥接提供：`src/dashboard.js`、`src/operations-routes.js`，以及 `public/dashboard.*` 和头像；只需重载桥接，QQ和DSH不必重启。Nginx的 `deploy/nginx-dashboard.conf` 包含于既有HTTPS server，不新增公网端口。Host设为13100回环，仅精确预算设置路径增加POST，其他公开路径仍只允许GET。

撤回时停止工作台公开反代，从你自己的部署备份恢复 bridge/harness 及相关文件后重载桥接；保留配置、账号设备、记忆、账本和新聊天。个人备份与验收记录不随公开源码提供。
