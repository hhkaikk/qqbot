# 识图功能

在允许的群里 @大肥鱼发送图片、截图或表情，或在允许的私聊里直接发送。可以说“读一下截图里的报错”“比较这两张图”“只看第六张”。无需额外配置视觉API，仍使用当前DSH模型。

机器人按需调用 `qq_get_message_images`，图片前紧邻原消息和原序号标签，部分图片失败不会挤占其他图的序号。可选 `imageIndices:[2]` 只下载第二张；默认单次最多5项媒体，后续图片可按原序号另取。一次请求仍受图片总字节、像素、会话令牌和白名单限制；不会自动把所有历史图片反复发给模型。

截图优先核对关键原文、数字和单位；辨认不出的细节要明确不确定。看图失败不能假装成功，最多重试失败项一次。修复不等于所有小字、复杂场景或低清照片均可准确识别，未新增OCR服务或更换模型。

## DSH 0.2.0-rc.2 大图兼容补丁

此版本 `@deepseek-ai/dsh-mcp-client` 的分组重复base64正则在数MB图片上会报 `Maximum call stack size exceeded`，图片被降级成 `image unavailable` 文本，模型实际看不到。补丁仅将正则改为不重复分组的等价字符检查，保留原来的Buffer编码往返校验，不降低清晰度、不放宽图片权限。

安装脚本已接入补丁；重新安装相同DSH版本后会重新应用。独立检查或应用：

```text
node scripts/patch-dsh-image-base64.mjs --modules <DSH安装目录>/node_modules --check
node scripts/patch-dsh-image-base64.mjs --modules <DSH安装目录>/node_modules
```

只接受已验证的0.2.0-rc.2和精确源码形状，未知版本停止并保留源码。应用前创建原模块备份，重复应用无改动；修改后需重载DSH。升级到其他版本时需重新验证，不能强行套用补丁。

离线回归：`node --test scripts/test-image-enhancements.mjs scripts/test-dsh-image-base64.mjs scripts/test-qq-model-view.mjs`。

服务器只读验证：`scripts/verify-dsh-image-projection.mjs <会话key> <消息ID>` 复用真实MCP和DSH附件实现，临时附件库用完删除，不发QQ消息、不调用模型；只有模型元数据查询为隔离测试替身。`scripts/test-dsh-vision-live.mjs` 会创建临时会话，向当前模型提交两张生成的测试图来验收文字、数字、多图对应和形状颜色，有少量API用量；结束后清理并归档，不发QQ消息。
